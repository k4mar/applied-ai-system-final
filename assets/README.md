# assets/

Images used by the top-level README.

The architecture diagram's source of truth is
[`../diagrams/architecture.mmd`](../diagrams/architecture.mmd) (Mermaid). GitHub renders
it directly inside the main README, so no PNG export is committed. To export one, paste the
`.mmd` file into <https://mermaid.live> and download the PNG into this folder as
`architecture.png`.
